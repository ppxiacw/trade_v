多周期形态与突破判断

看股票时先扫各周期 K 线有没有趋势或形态；若是「选择方向」的形态，再结合板块、龙头股、大盘，判断是向上突破还是突破失败。

看盘三步

1. 多周期扫描

  • 日线 / 60分 / 30分 / 15分等
  • 找：趋势、整理、关键位形态

2. 识别形态性质

  • 趋势型：已有方向，跟随
  • 抉择型：临近突破，等确认

3. 三要素定方向

  • 板块是否走强
  • 龙头是否带头
  • 大盘是否配合

4. 结论

向上突破 或 突破失败

方向确认话术

形态出现时问 这是选择方向的形态吗？如果是，板块、龙头、大盘现在偏多还是偏空？

偏多共振 板块强 + 龙头强 + 大盘不拖后腿 → 倾向向上突破

偏空 / 不配合 板块弱 / 龙头走弱 / 大盘走坏 → 倾向突破失败

对照表

观察点 看到什么 怎么用
各周期 K 线 趋势、整理、形态 先判断有没有可交易结构
选择方向形态 箱体末端、三角收敛、关键阻力/支撑抉择 不提前猜，用外盘环境确认
板块 同板块是否整体走强 个股突破需要板块支撑
龙头股 龙头是否带头向上 龙头弱，跟风突破成功率低
大盘 指数是否配合 / 拖累 大盘走坏时，突破更易失败

和 B/S 确认流的衔接

  • 本图先解决：方向是「向上突破」还是「突破失败」。
  • 若判断向上突破，再进入买入确认：买强的，并问弱的是否止跌上涨。
  • 若突破失败或强的开始走弱，再进入卖出确认。
