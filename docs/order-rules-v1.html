下单规范 v1

把炒股心得固化成「下单前必须回答的问题」。以后程序按规则 ID 弹确认： 硬禁止 必须确认 不过 → 拦截下单； 警告 → 二次确认。

总流程 两种单 盘前 结构 方向 买入 持仓 卖出 勾稽 硬禁止 补充心法

总流程（程序串联顺序）

盘前预案 + 定规矩(做T/只B/只S) → 看盘自问：形态 / 波浪 / 均线缓推 / 30分第几波 → 多周期形态：板块+龙头+大盘 → 突破 or 失败 → B确认：买强的？弱的止跌上涨了吗？ → S确认：强的走弱了吗？弱的已弱一阵子了吗？ → 按单类型执行：超短立刻砍 / 趋势单忍波动

关联图： 看盘自问 · 形态突破 · B/S确认 · 机器可读：order-rules-v1.json

两种单子（先选类型，再套规则）

ULTRA_SHORT 超短博弈突破

依据：1分 / 5分信息即可开仓。
约束：见势不对立刻砍仓，对噪声零容忍。

SWING_30M_DAILY 30分/日K趋势单

依据：30分钟甚至日K。
约束：止损设好，中间波动不过敏，大方向对即可。

一、盘前

R01必须盘前推演：下跌怎么走？上涨怎么走？最好/最差情况与点位预案都写好了吗？
R02必须前一日是否定好每只票规矩：做T / 只B / 只S？
R05必须止盈位或要跌到的位置算好了吗？算好后只等，别揣测它怎么走过去。
R03警告美股次日偏弱？是否留仓位准备早盘低吸做T？
R04警告大盘情绪差：条件单少挂，等个股+大盘信号再打重仓？
R06警告竞价买入给自己余地：分批买？还是挂高一点？

二、结构识别（尽早判断）

R10必须有没有形态？有没有波浪趋势？还是沿均线缓推？
R11必须都没有 → 前一个30分钟大趋势是第几波？第三波回调会很深。
R12心法30分三浪上涨：回调更深；第一前期高点可能撑不住，二浪支撑大概率可撑。
R13警告拉出距离不够 → 回调更深；突破距离不远且起点太低 → 回踩也可能深。
R14警告走趋势时过高强度很重要：要拉开距离才能再谈回踩。
R15心法见底：背离或加速。背离级别决定调整深度。
R16警告沿均线缓推：小阴小阳不重要，除非放巨量。

三、方向与环境

R20必须比大盘强弱看大级别；小级别一两分钟不能作数。
R21必须选择方向形态：用板块 + 龙头 + 大盘判向上突破还是突破失败。
R22必须个股日内买卖结合板块和指数的支撑压力与走势。
R25必须大盘下跌趋势：灯信号抄底个股；大盘上涨趋势：看点位买入。
R23警告任意指数/板块新高附近防大回调。
R24警告指数高点可用最强板块高点交叉印证。
R26警告别一见突破就当突破走势；也可能是趋势浪，会回落到突破点下方。

四、买入约束

R30必须看弱做强：弱的刚止跌/见底时，买最强的。
R31必须竞价抄底：买ETF，不买个股。
R32必须有效突破看成交量；早盘不放量，不认突破结构。
R33必须最近这波涨幅量是否比之前上涨时量大？涨速是否够？
R34必须30分钟走势复杂、毛刺多 → 不买。
R35必须日线刚回调且离目标支撑太远 → 不短做多（反之亦然）。
R36必须下跌趋势抄底：周/日要有很强支撑，否则等日线止跌再入。
R37必须二次回踩支撑 → 不做。
R38必须早盘翘头上拉再砸的当天 → 不买。
R40必须银行企稳且有向上趋势 → 不做个股。
R42必须不做最近低点=最低点的多（除非更大级别超低止损抄底）。
R39警告拉太早当天再下杀概率大；临近下午见底抄底胜算更高。
R41警告跌破区间再回来：若下跌末段，有可能直接突破。

五、持仓 / 止盈止损

R50必须止盈：形态对称 / 均线 / 整数点。算好后等，不猜路径。
R51必须第一天进场误判 → 第二天竞价直接走。
R52警告下跌抄底第一把亏且当日形态未好 → 次日止盈放低，用5分钟近高而非30分。
R53心法之前有过回踩，一般不会再回头。
R54警告抛压大的一天洗不够 → 次日早盘可能再杀一次。
R55心法光头光脚阳线后，第二根阴线不破阳线1/2 → 趋势还在。

六、卖出约束

R60必须卖看最强：弱的已跌一会儿，强的刚开始跌 → 卖强的/全卖。
R61必须先砸再拉的当天 → 不卖。
R62必须不做最近高点=最高点的空（除非更大级别超低止损摸顶）。
R63警告大趋势后不直接A杀：至少30分多次大阴或多次顶背离。常见：MACD绿柱→拉前高双顶→猛跌。
R64警告高低点抬高重要；突破无力、回调过快是反转信号。

七、勾稽品种

R70必须不做勾稽里强势的空、弱势的多。
R71必须上涨看强的能否先过压力；下跌看弱的能否在支撑挺住。
R73必须不同步时别乱空：A上升且B筑底 → 等A回调结束、共振时追B多（创业板/恒生科技教训）。
R72警告强的新低抬高、弱的不破新低；有时强不破新低，弱也能被拉起。
R74心法顺趋势支撑压力有效；逆趋势支撑不一定有效，但反弹到压力做空成功率高。

八、硬禁止（程序直接拦截）

X01硬禁未算止盈/止损就下单，并盘中揣测路径
X02硬禁用1–2分钟级别判断相对大盘强弱
X03硬禁竞价抄底买个股
X04硬禁二次回踩支撑再做
X05硬禁翘拉再砸当天买；先砸再拉当天卖
X06硬禁银行企稳向上趋势时做个股
X07硬禁勾稽做强势空 / 弱势多
X08硬禁开盘后不再看日线（日线每天都要看）
X09硬禁30分钟复杂毛刺走势冲动开仓

补充心法（暂作提示，不全做硬拦）

  • 支撑压力常在一串阴线里的那根阳线附近；反弹也看这附近。
  • 往下找支撑：看哪个被回踩过；没被回踩的更可能被回踩。
  • 关键点位前若已提前盘整，该点位可能失效。
  • 突破回落完全可能回到突破点下方。
  • 观察股性：拉升后洗盘一次缩量还是两次；拉升第三日下杀回拉？高位深洗、刚启动浅洗。
  • 缩量回调过程不能有反弹波峰，否则削弱反弹动力。
  • 普涨行情，抱团股容易解散。
  • 大趋势后做空至少要在30分看到多次大阴或多次顶背离；常见震荡下行。

后续程序怎么用

  1. 下单时选择：ULTRA_SHORT / SWING_30M_DAILY
  2. 按阶段拉取 order-rules-v1.json 中对应 checks
  3. hard/must 未勾选确认 → 阻断
  4. warn → 二次确认弹窗
  5. 与现有三张流程图串联成完整下单闸门
